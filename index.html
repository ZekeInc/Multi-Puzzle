How to play

Place one O in every row, every column and every colour group. Os can't touch each other, not even diagonally. Each puzzle has exactly one solution.

Tap a square once for ✕ (not an O), twice for O, three times to clear. Drag across squares to mark several ✕ at once.

How to play

Sort the numbered squares so that no box holds more than one number.

Tap a box to pick up its top square (and any matching squares under it), then tap another box to drop them there. You can only drop onto an empty box or onto the same number, and each box holds 4 squares.

Use the extra empty boxes as space to shuffle squares around. Every puzzle can be solved.

Tap ⚙ Preferences to choose the number of colours, extra boxes, how many squares fit in a box (per box) and how many empty spaces each box starts with. More empty spaces make it easier.
